# A Path's Access is set for the whole Path, not per version

A Guide decides once, for the whole Path, whether a User may Add it straight
away (Free) or has to Request it first (Permission required). Every
published version of the Path has the same Access. This matches Open and
Close, which are also per Path. It also gives the Guide one list of
Requests, not one list per version. A Request itself is still for one
version, because Add is: Access says whether you have to ask, not what you
get.

## Considered Options

- **Access per version.** This would let a Guide offer a free intro
  version and a gated full one. But every Request would then belong to a
  version and the Guide's list would be split by version, for a
  difference nobody has asked for yet.

## Consequences

To offer a free intro and a gated full Path, a Guide makes two Paths.
Switching to per-version Access later means a migration that copies each
Path's value onto its versions, and deciding which version each pending
Request belongs to. That is cheap while Requests are few.
