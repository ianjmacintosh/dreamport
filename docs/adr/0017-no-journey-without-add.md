# No Journey on another User's Path without Adding it first

A User can start a Journey on Dream Sequence or on their own Path straight
away, but on a Path another User made only after Adding one of its published
versions, which gives them their own read-only copy. Opening a Guide's link
shows the Path and offers Add, never Start on Path directly. Add is the gate
a Purchase will sit behind: paying is how a paid version gets Added, so every
Journey on someone else's Path already runs on a copy the User holds, free or
bought.

## Considered Options

- **Start straight from the link, Adding implicitly.** One step fewer for a
  free Path, but a paid Path would then need a different flow, and a Journey
  would exist on a Path the User never chose to keep.
- **Journeys on the Guide's original, no copy.** Breaks as soon as the Guide
  closes, unpublishes or deletes it (ADR-0016's extension, #188).
